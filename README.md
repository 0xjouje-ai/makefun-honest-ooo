A brutally honest but still manager-safe out-of-office auto-reply, written by a tiny Node program. It admits the sender is relieved to be offline, that the inbox holds 1,400 unread emails read with zero enthusiasm — and still says thank you for your patience.

## Run it

```sh
node main.ts
```

It writes the single auto-reply (192 characters) to `/output/entry.txt`.
